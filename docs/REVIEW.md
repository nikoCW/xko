# 原版审查与本次修改

原版基于仓库 main 的 `server.py`、README 和 skill 检查。它是公开行情分析程序，没有账户接口，不能用于自动实盘。

| 原问题 | 风险 | 修改 |
|---|---|---|
| 按24h涨幅选最大分数候选 | 容易追高，缺少独立入场证据 | 成交额/价差筛选，15m收盘突破+后续回踩、放量、4H趋势和1H追价限制 |
| 没有已收盘K线时退回原始K线 | 把未完成走势当确认 | 移除回退；关键分析要求足量、连续、及时的收盘K线 |
| 固定1R/2R目标，无仓位/成本 | 实际风险和盈亏比与表面数字不符 | Decimal计算张数/币数、费用和滑点后盈亏比、现金和风险预算 |
| 只有公开GET请求 | 无法读账户、交易、判断成交 | 增加签名私有API、精确执行预览、下单/撤单、成交与保护核对 |
| 公开无认证，关闭DNS重绑定保护 | 加入API Key后会暴露账户能力 | 私有凭据要求Bearer鉴权，域名白名单、HTTPS接口白名单、不跟随重定向 |
| 没有订单日志及恢复状态 | 超时或重启后重复下单 | SQLite状态、事务领取、固定client ID、未知结果锁定与只读核对 |
| 没有网格与提醒实现 | 无法兑现相关能力 | 现货网格规划；后台价格/执行事件及可选webhook；明确未实现原生网格机器人 |

## 已验证

离线测试包括规则、金额精度、合约面值、成本后收益、K线缺口/未收盘、鉴权与签名、超时不重试、重复确认、过期预览、报价漂移、模式切换、保护缺失、减仓方向、日志重启、提醒去重及后台只读。MCP工具注册和健康检查另做烟雾验证。

## 尚未验证与实际限制

- 没有使用OKX私有密钥；没有在模拟盘或实盘真实下单。Mock测试不能证明某地区、账户模式或产品接受FOK附带止盈止损；若不支持必须明确拒绝，不能降级去掉保护。
- 没有策略回测、收益评估、行情断流压力测试、真实webhook投递或生产部署。
- 执行只支持FOK与预览撤单；不支持改单、自动追踪止损、双向持仓、全仓、原生网格启动或无人值守实盘。保护失败会阻止新开仓并提醒，但不会未经确认自动平仓。
- 新增风险要求账户没有未平合约、普通/策略挂单或机器人资金，且不加同币库存。这是对尚未实现完整多策略风险合并的明确限制。
- API快照不是交易所原子事务；外部手动操作或其他机器人仍可能产生竞争。使用专用子账户、单个本服务实例，避免其他进程同时交易。
- 本服务不是多租户OAuth产品。令牌认证适用于支持Header的客户端；其他客户端需部署OAuth网关。监控不会主动把消息推入ChatGPT对话。
- 持久化状态必须保留；不同账户及模式用独立数据库。保护状态核对只覆盖本服务提交的订单，账户总览仍需检查外部订单。
- 固定手续费下限/滑点和保证金距离检查是保守估算，不是成交成本或强平价保证。跳空、流动性不足、交易所故障可能超过止损估算。
